# Монитор принтеров для Windows

Это тестовый проект, который разрабатывается для более удобного контроля сетевой печатной техники на производстве. Локальная панель показывает доступность принтеров и типичные ошибки устройства по SNMP. Список устройств хранится в SQLite, дополнительные Python-библиотеки не нужны.

## Запуск

1. Установите Python 3.9 или новее.
2. Откройте PowerShell в папке проекта.
3. Запустите `python desktop_app.py`.
4. Откройте в браузере `http://127.0.0.1:8765`.

Добавляйте и удаляйте принтеры прямо в панели. Данные сохраняются в файле `printers.db` рядом с программой. Проверка состояния выполняется автоматически каждые 30 секунд; кнопку ручной проверки можно нажать в любой момент.

## Ошибки принтеров

Для получения ошибок принтер должен поддерживать Printer-MIB, а SNMP должен быть включён (обычно UDP-порт 161). По умолчанию используется community `public`. Если в вашей сети задано другое значение, установите его в PowerShell перед запуском:

```powershell
$env:PRINTER_SNMP_COMMUNITY = "ваше-значение"
python desktop_app.py
```

Если SNMP недоступен, панель всё равно продолжит проверять TCP-порт печати. Для принтеров без SNMP снимите галочку при добавлении.

Панель по умолчанию доступна только на этом компьютере. Не меняйте адрес `127.0.0.1`, если не настраивали защиту для доступа из сети.

## Автозапуск при входе в Windows

1. В папке проекта нажмите правой кнопкой на `start_monitor.bat` и создайте ярлык.
2. Нажмите `Win + R`, введите `shell:startup` и нажмите Enter.
3. Переместите созданный ярлык в открывшуюся папку автозагрузки.

После следующего входа в Windows монитор запустится свёрнутым. Панель будет доступна по адресу `http://127.0.0.1:8765`. Чтобы отключить автозапуск, удалите ярлык из папки автозагрузки.
